# 01_docs — 项目管理文档

存放过程性、管理类文档（不放代码和数据）：

- **会议纪要**：命名 `MMDD_主题.md`（如 `1016_kickoff.md`、`1021_M1_设计冻结.md`）。当日会议当日归档，写明决议与分工。
- **设计决策登记表**（E3 维护）：`design_decisions.md`，每条决策记录 选项 / 理由 / 日期，供报告写作与 Q&A 引用。
- **组员环境登记表**：`env_record.md`（C1 环境记录：每人 OS / MySQL 版本，**10-17（M0）前**填好并 commit）。
- **关卡签字扫描**：11-02 四道质量关卡（ER / SQL / 数字 / 格式）的打勾签字照片或截图。
- **执行方案与官方要求 PDF**：因仓库为 public，两份 PDF 存组内共享盘，不提交到 GitHub。

| 相关任务 | 说明 |
|---|---|
| E1/E4 | 每次全组会（kickoff、M1–M4）纪要在此归档 |
| A2/A3/B4 等 | 里程碑通过的决策汇总进设计决策登记表 |
