\subsection{Limitations}
The synthetic sample demonstrates system behaviour under the selected generation rules. Parameters are based on full-dataset RideAustin statistics, so the comparison is descriptive and independent holdout validation remains unestablished. Unmatched requests are absent, limiting demand and matching analyses. Single-run measurements on one instance do not establish P95, throughput or production-scale performance. The 150 drivers and approximately 180 LUXURY trips also limit subgroup comparisons.

% 中文概述：重复测量查询、定义负载压测、独立编号对账，以及请求记录、副本和归档评估。
\subsection{Future Work}
Future work should repeat the five complete queries to measure P95 and test throughput under a defined transaction workload. An independent expected set of trip IDs would support reconciliation checks. Further extensions include recording pre-dispatch requests, evaluating a read replica and archiving historical records before removing expired online data. These extensions also require correctness and performance evaluation.
