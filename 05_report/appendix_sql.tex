\subsection*{Data Generation Entry}
The dataset is regenerated by \texttt{import\_data.py} (repository path \texttt{02\_sql/}): every random choice uses the fixed seed 534, distribution parameters are the RideAustin-calibrated values of decision D-10, and the script ends with built-in acceptance checks (row counts and key ratios), so any member rebuilds identical data from the same repository scripts (constraint C6). Full rebuild on a clean machine:

\begin{lstlisting}[language=bash,caption={Rebuild from scratch (idempotent, re-runnable)}]
mysql -u <user> -p < 02_sql/build.sql    # schema v1.0: base + extension + self-checks
python3 02_sql/import_data.py           # fixed seed=534 + built-in acceptance checks
\end{lstlisting}
