## 官方 ER 约定（评分点，务必遵循）

- 矩形 = 实体，属性写在框内，**主键斜体**
- 子实体中外键属性以 `*id` 标注
- 每条连线标注基数：`1:N` / `N:M` / `1:1`
- N:M 必须用关联实体拆成两个 1:N

`.drawio` 源文件必须提交（可编辑、可追溯）。
